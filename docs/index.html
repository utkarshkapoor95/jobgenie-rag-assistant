Architecture

RAG Pipeline

End-to-end retrieval-augmented generation with semantic search over resume embeddings.

1
Document Ingestion
PyMuPDF / PyPDF2 extract text from uploaded PDF resume
↓
2
Chunking + Embedding
RecursiveCharacterTextSplitter (400 chars) into all-MiniLM-L6-v2 (384-dim vectors)
↓
3
Vector Storage + Retrieval
Pinecone Serverless (cosine similarity, top-5 retrieval)
↓
4
RAG Chain + Generation
LangChain prompt templates + Groq LLaMA 3.3 70B (320 tok/sec)
↓
5
Structured Output
Skill gap table, pitch, interview questions, confidence dashboard
